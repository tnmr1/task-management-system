Task Management System

A full-stack task management web application built with Python, Flask, SQLite, HTML and CSS.

Features
- Add tasks
- Categorise tasks
- Set priority levels
- Mark tasks as complete
- Delete tasks
- Store tasks in an SQLite database

Technologies
- Python
- Flask
- SQLite
- HTML
- CSS

- User registration and login
- Edit tasks
- Due dates
- Dashboard analytics
